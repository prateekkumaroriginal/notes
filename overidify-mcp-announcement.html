Claude Code, Codex, and Cursor can now create, edit, and delete your Header, Switch, and Network Rules. Describe the rule you need, and your agent sets it up.

Rules take a while to set up

A Network Rule needs a request URL, a method, a status code, headers, a response body, and the websites it runs on. A Switch Rule needs every option and its headers. Mocking several endpoints or preparing test accounts means a lot of form filling.

Your agent already knows the API you're working on. Now it can create the rules too.

What agents can do

Read

List your rules or open one to see every setting.

Create

Add Header, Switch, and Network Rules.

Change

Edit any setting, turn rules on or off, and choose a Switch option.

Delete

Remove rules you no longer need.

Agents get the same checks as Settings. If something is wrong, such as an invalid URL or a header without a value, nothing is saved and the agent is told which field to fix. Valid changes apply right away and appear in Settings.

Get started

Step 1

Turn it on

Open Overidify Settings, click Agents, and turn on MCP server.

Step 2

Connect your agent

Click Copy prompt and download setup file and paste the prompt into your agent. It installs the helper and adds Overidify to its settings.

Step 3

Start asking

Open a new agent session and describe the rules you want.

To do it yourself, the Agents page also has the setup file and the configuration for each agent.

Only agents on your computer can connect

Local only

The server only accepts connections from your own computer.

Token required

Agents need an access token. Regenerate it any time to disconnect them.

Websites can't connect

Pages you visit in the browser can't reach the server.

Good to know

  • Chrome must be open with MCP server turned on.
  • Overidify asks for one new permission, “Communicate with cooperating native applications”. Chrome uses it to start the local helper.
  • After some updates, the Agents page asks you to run setup again.
  • If you use Overidify in two browser profiles, give each one its own port.
