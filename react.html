What is React?

React is an open-source JavaScript library for building user interfaces from reusable components.

Overview

React helps developers build pages whose content changes without a full reload. It is widely used for single-page applications, though it can also support server-rendered and static websites.

A React interface is split into components. Each component owns a small part of the page, such as a search box, navigation bar, or product row. Teams can combine and reuse these pieces across an application.

Why was React needed?

Traditional websites often loaded a new HTML document after each action. As web apps became more interactive, developers started changing the page directly with JavaScript. That worked for small pages, but large apps accumulated event handlers and DOM updates that were hard to keep in sync with application data.

Manual DOM updates

Every data change may require code that finds and updates the correct elements.

React's approach

Developers describe the interface for the current data. React updates the page to match.

The main idea

React makes interface code declarative. Instead of writing a sequence of DOM instructions, a developer describes what should appear for the current data. When that data changes, React renders the next version of the interface.

This model made large interactive interfaces easier to divide, reason about, and maintain. It also gave teams a consistent way to reuse UI code.

React's scope

React handles the interface layer. It does not prescribe routing, databases, authentication, or deployment. Projects usually add other libraries or use a React framework for those jobs.

In short, React was created to make changing, data-driven interfaces manageable as web applications grew larger.
