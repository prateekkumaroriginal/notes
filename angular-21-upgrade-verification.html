Firebase without AngularFire

FirebaseService now calls the Web SDK directly. Initialization is lazy, browser-only, and gated on each product's isSupported(). Remote Config updates run inside NgZone.run(). A returning user with a stored token previously never attached onMessage; that is fixed and must be checked, not assumed.

  • Grant notification permission on a fresh profile. A token is issued, the register-token API call succeeds, and the console shows no Firebase initialization error.
  • Send a test push while the tab is in the foreground. Exactly one toast or in-app notification appears. Two means the listener attached twice.
  • Reload as the same user. The stored token is reused, no second registration call fires, and a foreground push still surfaces once.
  • Background push. With the tab hidden, the service worker (firebase-messaging-sw.js) shows the system notification and clicking it opens the app.
  • Remote Config drives the UI. On a page that reads iosPayButtonsConfig, changing the remote value and reloading changes what renders. No manual click should be needed for the view to update.
  • Unsupported browser path. In Safari private mode or with notifications blocked, the app loads and no unhandled rejection appears.
  • SSR stays clean. Server output has no IndexedDB, window is not defined, or Firebase provider errors while requesting pages.

ngx-bootstrap 21 and the phone input

Two things changed under the application. Module.forRoot() is gone, so every module is imported bare. BsDropdownDirective.isOpen is a getter now, so code that assigned it uses toggle() or hide(). ngx-intl-tel-input still calls forRoot() and is patched.

Host listeners that lost their $event argument

Angular 21 type-checks host bindings. 49 @HostListener('window:scroll' | 'window:resize', ['$event']) decorators sat on handlers that took no parameters and were changed to pass nothing. Behaviour should be identical; confirm the listeners still fire.

  • Infinite scroll loads more. Home feed, creators list, collaborators, block users, basic see-more, merchandise store, VIP offers.
  • Resize handlers. Home, merchandise store, portfolio, sponsored ad, skyscraper preview modal, VIP offer list, advertisement details switch layout when the window crosses the mobile breakpoint.
  • Table sticky behaviour. The shared table component reacts to window scroll.
  • Click-outside handlers. Any component that closes a menu on document click still does so.

Known noise and deliberate holds

  • Lint still fails, as it did before. 890 findings remain from rules already in the v19 recommended set: prefer-standalone 541, template eqeqeq 67, no-output-on-prefix 50, and others. Two rules new in v20 recommended, prefer-inject and template/prefer-control-flow, are turned off with a comment because they are separate migrations.
  • Serverless main.js cannot be required in bare Node. It fails inside video.js's auto-setup, which needs window.setTimeout. This is unrelated to Angular and the target is not deployed anywhere.
  • Peer warnings from ng update. ng-ivs peers Angular 12, ngx-audio-player peers Material 17, primeng peered CDK 20 before its own bump. All compiled; both players are on the smoke matrix.
  • Control-flow migration was reverted. ng update rewrote 659 templates to @if and introduced four template errors. Templates stay on *ngIf.
  • generate-static-routes logs 400s. The QA backend rejects VIP-offer and store lookups for some creators. This is backend data, not a build failure, and the run still exits 0.
  • Sass deprecation warnings dropped from 288 to 226. Still noisy, still not blocking.
  • Local environment.ts and regenerated marketing constants are not committed. They are the developer's local QA switch and prefetch output respectively.

Stop the release if any of these fail

  • A foreground push produces zero or two notifications, or a fresh user cannot register a token.
  • The phone country dropdown does not open on signup, or the browser console shows forRoot is not a function.
  • A dropdown toggled from code stays open, or infinite scroll stops loading on the home feed.
  • A permitted host receives an empty <app-root> or server output reports an Angular runtime error.
  • Wallet checkout, Stripe Connect, audio playback, live video, or a representative white-label tenant regresses.
