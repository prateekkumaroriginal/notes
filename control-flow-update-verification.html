Live templates now use @if, @for, and @switch. 550 HTML files plus the price-display inline template. Routing, SCSS, and business logic are unchanged.

What changed

A whole-app schematic pass ran out of memory at about 8 GB. I ran Angular's official schematic per directory instead.

NODE_OPTIONS=--max_old_space_size=10048 npx ng generate @angular/core:control-flow --path=src/app/components --defaults --interactive=false

I put CommonModule and the schematic's TypeScript formatting back. Eleven trackBy* methods now take a second unused argument because @for calls track fn($index, item).
