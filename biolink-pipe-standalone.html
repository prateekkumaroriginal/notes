Two pipes share the name

There are two classes called BioLinkPipe.

  • cast-link.pipe.ts exports the one named bioLink. Creator profiles use it on the bio. It was already standalone.
  • isLink.pipe.ts exports the one named isLink. It wraps URLs in empty <a> tags. No template uses it, and no file imports the class. It still sat next to pipes that posts and messages do use, with standalone: false.

This commit only drops that flag from the unused pipe, so it matches the other pipes in the same file. I did not delete it. Deleting unused files is a later follow-up.
