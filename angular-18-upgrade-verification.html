How to run it

Put nvm Node 20.19.6 first. Serve dist/TopFans/server/server.mjs after npm run prerender-all-qa, or the qa --prerender=false output. Do not use npm run build-dev. Do not use Docker. Do not treat ng lint or ng test as gates.

Hit Express URL parse first: trailing slash, unknown route, then ?key=. Product clicks come after that. Angular 17 is signed off. Do not reopen 17 bugs on this list.
