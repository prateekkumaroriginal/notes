Development notes

AppModule is gone

The last two NgModules were the shell. The browser now calls bootstrapApplication. The server forwards BootstrapContext. Decorator inputs stay as they were. That rewrite is a different PR.

commit 8d2a75fc01 t3code/standalone-appmodule-migration PR 10871

What changed

Feature routes were already standalone. This only moves root bootstrap and the provider list. I deleted AppModule and AppServerModule.

Calls I made

  • Kept provideZoneChangeDetection() in appConfig. Angular 21 standalone bootstrap is zoneless unless you say otherwise.
  • Kept importProvidersFrom(ModalModule) as-is. No forRoot(). Toastr and Stripe still use their forRoot configs. NgRx uses provideStore with the same five keys and the same loose runtime checks.
  • Left withEventReplay() and withNoHttpTransferCache() on the client config.
  • Did not rename lamda.js. serverless.yml still lists lambda.js, which is not in the checkout. If that path is still deployed, someone has to pick one filename.
