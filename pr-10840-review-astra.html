What I checked

Routes and behavior stay the same

An AST comparison found that 87 of 93 changed files differ only in imports, standalone metadata or comments. The other six cover route wiring, three deleted modules and the removed video binding. No component method body changes.

The dashboard route array is identical after removing the new providers and accounting for its exported name. The parent app route remains lazy. See the dashboard route and provider list.

Dashboard keeps its stateful providers

The top-level dashboard route provides all five services and pipes previously supplied by DashboardModule. It also provides isPostCollaboratorPipe, which injects MyProfile and must use the dashboard's DashboardModuleService instance.

The shared root provider registrations are unchanged. They retain the dependencies used by root-created modals and the existing multiselect and circle-progress configuration. See shared root providers.

Compiled templates retain their dependencies

Fresh Angular compilation emits 646 components, compared with 650 in the saved base compilation. After normalizing import aliases, 619 have identical dependency lists. Another 26 only lose ngx-intl-tel-input's NativeElementInjectorDirective. I checked that none of those 26 templates contains a phone input.

ForumPostDetailComponent resolves NgbCarousel and NgbSlide through the package's main export instead of its carousel entry. The installed package re-exports the same classes.

The four components absent from the new output are ProfileDetailComponent, SubscriptionSelectModalComponent, SubscriptionPlanDurationModalComponent and the old typeahead SearchBarComponent. Their active import chain ended at the removed modules. The typeahead's remaining template use is inside an HTML comment.

Video cover selection still has its data path

The deleted coverImage binding targeted an input that VideoPlayerV3Component does not declare. The old CUSTOM_ELEMENTS_SCHEMA hid it. VideoTrimComponent still calls the player's setCoverImage method when a cover is selected. See the existing cover-selection method.
